agent-scan

Your coding agents repeat their own mistakes. See how often.

A free skill for Claude Code and Codex. It reads your session history on your own machine, prints one card, and then your agent finds the cause of its most repeated failure and proposes a fix.

Open in Claude Code

Works in Claude Code, Codex or any agent that can run a shell command. The button opens Claude Code with the prompt typed in; nothing runs until you send it.

Install it as a skill

In Claude Code:

/plugin marketplace add AKarode/skills
/plugin install akarode@akarode

Then run /akarode:agent-scan. For Codex, Cursor, Gemini CLI and other agents:

npx skills add AKarode/skills

Or paste one prompt

No install. Your agent downloads the scanner, checks its fingerprint, runs it and explains the card.

Show the prompt 
Run a read-only scan of my coding-agent history and explain what it found.

1. Download https://raw.githubusercontent.com/AKarode/skills/agent-scan-v1/plugins/akarode/skills/agent-scan/scripts/scan.py to a new temporary folder.
2. Check that its SHA-256 is ad2ef0f7db81667085cfde73496f419a96c9048a9369073b7a059377c91a17fa. If it is different, stop and tell me.
3. Skim the file and tell me in one line whether it only reads local session files and makes no network calls.
4. Run it with python3 -I and show me the card exactly as it prints.
5. In plain words, tell me the two numbers that matter most and why.
6. Take the top entry under "Your most repeated failing commands". Look at a few of those failed attempts in my recent sessions to find the cause, then propose one concrete fix: a line for my agent instructions file (CLAUDE.md or AGENTS.md) or a hook. Change nothing until I say yes.
7. Offer once to share my card anonymously: build a link to https://tally.so/r/ODpeWA with the card's numbers as query parameters (v=1, via=prompt, days, harnesses, sessions, spend_usd, shell_calls, fail_pct, repeat_pct, cd_pct, top_repeat_count). Numbers only. Do not send my data anywhere yourself.

What happens to your data

  • The scanner is one file of standard-library Python you can read first. It reads your session files without changing them and makes no network calls.
  • The card holds counts, dollars and percentages only. The names of your repeated failing commands stay on your screen, for your agent to work from.
  • Sharing is opt-in. At the end your agent offers a link with your card's numbers; nothing is saved unless you open it and submit.
